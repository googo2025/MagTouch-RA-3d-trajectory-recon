# Publication checklist

The English text and evidence are prepared; the following author-controlled items remain before actual submission.

- Replace author names, order, affiliations, corresponding author and ORCID placeholders.
- Confirm the supplier-derived silicone fields and any fabrication details not preserved in the historical record.
- Confirm funding, competing interests, contribution and originality statements.
- Review and approve the disclosure of AI-assisted analysis and writing.
- Review original replay clips for visible interface paths and identifying text.
- Select appropriate software, data and media licences if an openly licensed release is intended.
- Confirm the release tag `sna-a-revision-2026-09-21`; add an archival DOI later if one is actually assigned.
- Check the target journal's current submission system and guide for authors.

The analysis scripts perform no submission, network operation, licence grant or experimental acquisition.
